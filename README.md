## 📌 Introduction
This is a simple and responsive front-end website built with **HTML**, **CSS**, and **JavaScript**. The site serves as a personal portfolio and includes multiple sections such as home, about, and contact. The design is clean, mobile-friendly, and focuses on good user experience.

## ✨ Features
- Fully responsive layout (works on mobile, tablet, and desktop)
- Smooth scrolling and navigation
- Interactive elements with vanilla JavaScript
- Modern and minimalist design

## 🛠️ Technologies Used
- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, and animations
- **JavaScript (ES6+)** – DOM manipulation and interactivity
